## Referencias bibliograficas

Objetivo desta secao:

- conectar cada referencia ao PDF correspondente
- registrar autores, titulo e resumo
- descrever brevemente do que se trata o trabalho
- manter um indice pratico para consulta rapida

### Campos sugeridos para cada referencia

- `Referencia`: citacao bibliografica completa
- `Autores`: autores principais
- `Titulo`: titulo do trabalho
- `Ano`: ano de publicacao
- `PDF`: caminho ou link para o arquivo PDF
- `Resumo`: resumo curto do artigo
- `Tema`: assunto principal do trabalho
- `Contribuicao`: por que este trabalho e importante para o projeto
- `Observacoes`: notas livres

### Template de preenchimento

```md
#### Referencia 01
- Referencia:
- Autores:
- Titulo:
- Ano:
- PDF:
- Resumo:
- Tema:
- Contribuicao:
- Observacoes:
```
