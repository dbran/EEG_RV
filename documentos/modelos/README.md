# Modelos de Documento

Coloque nesta pasta o arquivo `.docx` modelo que deve ser usado como base de formatação do documento final.

Nome sugerido:

- `template_artigo.docx`

Uso esperado:

- o conteúdo-base é escrito em Markdown
- as referências podem ser mantidas em `documentos/referencias/referencias.md`
- o script em `python/gerar_documento_exemplo.py` prepara um documento estruturado
- quando houver um modelo `.docx` e uma ferramenta de conversão instalada, a exportação final pode seguir o padrão visual do template

Exemplo de organização:

- `documentos/modelos/template_artigo.docx`
- `documentos/modelos/topicos_exemplo.json`
